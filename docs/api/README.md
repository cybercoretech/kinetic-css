# Components

Kinetic CSS ships a comprehensive set of components for building applications. Uses **Roboto**, **Montserrat** from Google Fonts for typography.

## Core components

| Component | Class | Description |
|---|---|---|
| Card | `.k-card` | Container-aware card with adaptive layout |
| Button | `.k-button` | Primary, outline, danger variants |
| Field | `.k-field` | Form field with label and input |
| Input | `.k-input` | Text input with focus styling |
| Select | `.k-select` | Dropdown select |
| Textarea | `.k-textarea` | Multi-line text input |
| Badge | `.k-badge` | Status badge |
| Nav | `.k-nav` | Navigation bar |
| Divider | `.k-divider` | Horizontal rule |

## Navigation patterns

- `.k-header` — top header bar
- `.k-footer` — footer bar
- `.k-breadcrumb` — breadcrumb navigation
- `.k-nav` — navigation links

## Application patterns

- `.k-dialog` — native `<dialog>` modal
- `.k-tabs` — CSS-only tab panels
- `.k-accordion` — `<details>` accordion
- `.k-menu` — CSS disclosure menu
- `[data-k-tooltip]` — tooltip via data attribute

## Feedback & data

- `.k-alert` — alert banner (info/success/warning/danger)
- `.k-table` / `.k-table-wrap` — responsive table
- `.k-skeleton` — loading skeleton
- `.k-progress` — progress bar
- `.k-spinner` — loading spinner
- `.k-avatar` — avatar circle

## Layout patterns

- `.k-shell` — centered container
- `.k-prose` — reading-width content
- `.k-stack` — vertical flex
- `.k-cluster` — wrapping inline controls
- `.k-grid` — auto-fit grid
- `.k-split` — two-column split
- `.k-center` — centered content
- `.k-flow` — vertical rhythm
- `.k-region` — section padding
- `.k-layout` — sidebar layout with named container breakpoints
- `.k-pagination` — pagination controls
- `.k-carousel` — scroll-snap carousel
- `.k-toast` — toast notification
- `.k-form` — form grid
- `.k-sidebar` — collapsible sidebar

## Utilities
