# Accordion

Native `<details>`/`<summary>` accordion.

## Usage

```html
<details class="k-accordion">
  <summary>Question</summary>
  <div class="k-accordion__panel">Answer goes here.</div>
</details>
```

## CSS classes

- `.k-accordion` — container
- `.k-accordion__panel` — collapsible content

## Motion token

`--k-card-duration`, `--k-card-ease`
