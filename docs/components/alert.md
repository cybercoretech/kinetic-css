# Alert

Alert banner with severity variants.

## Usage

```html
<div class="k-alert k-alert--info" role="status">
  <p class="k-alert__title">Heads up</p>
  <div class="k-alert__body"><p>Something happened.</p></div>
</div>
```

## Variants

- `.k-alert--info` — blue accent
- `.k-alert--success` — green accent
- `.k-alert--warning` — amber accent
- `.k-alert--danger` — red accent
