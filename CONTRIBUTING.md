# 🚀 Contributing to Kinetic CSS

Thank you for your interest in contributing to **Kinetic CSS**! 🎉

## 🛠️ Getting Started
1. 🍴 Fork the repository on GitHub.
2. 📥 Clone your fork locally: `git clone https://github.com/cybercoretech/kinetic-css.git`
3. 📦 Install dependencies: `npm install`
4. 🌿 Create a feature branch: `git checkout -b feature/amazing-feature`

## 🧪 Testing & Validation
- Run tests: `npm test` 🧪
- Run linter: `npm run lint` 🔍
- Run build script: `npm run build` 📦

## 📋 Pull Request Guidelines
- 📝 Ensure all code adheres to style guidelines and stylelint checks pass cleanly.
- 🧪 Include test coverage for new features or bug fixes.
- 💬 Write clear, concise commit messages detailing the "why" of your changes.
- ✨ Open a Pull Request against the `main` branch.
