cybercore / kinetic-css · v0.2.0

Fluid by nature.

A responsive framework that adapts to the space a component actually has — not just the size of the screen. No JavaScript. No compiler. No build step. Modern CSS: cascade layers, custom properties, clamp(), container queries, light-dark(), and OKLCH colors.

NATIVE FOUNDATION

HTML + CSS

Kinetic is CSS-first. Import the stylesheet and use its classes, custom properties, fluid sizing, container queries, and design tokens. The core framework needs no JavaScript runtime or build step.
🟨

LANGUAGE COMPATIBILITY

JavaScript

The optional @cybercoretech/js package provides runtime functionality. It is an add-on; the core CSS framework does not depend on it.
🔷

LANGUAGE COMPATIBILITY

TypeScript

The @cybercoretech/ts package provides TypeScript declarations for Kinetic CSS runtime controllers.
⚛️

FRAMEWORK COMPATIBILITY

React

Import the stylesheet and apply Kinetic classes in JSX. React is listed as a development dependency in the repository, not as a dedicated official Kinetic adapter package.
💚

FRAMEWORK COMPATIBILITY

Vue

Import the stylesheet and apply Kinetic classes in Vue templates. Vue is listed as a development dependency in the repository, not as a dedicated official Kinetic adapter package.
🔥

FRAMEWORK COMPATIBILITY

Svelte

Import the stylesheet and apply Kinetic classes in Svelte markup. Svelte is listed as a development dependency in the repository, not as a dedicated official Kinetic adapter package.
