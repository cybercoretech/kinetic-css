cybercore / kinetic-css · v0.2.0

Fluid by nature.

A responsive framework that adapts to the space a component actually has — not just the size of the screen. No JavaScript. No compiler. No build step. Modern CSS: cascade layers, custom properties, clamp(), container queries, light-dark(), and OKLCH colors.

NATIVE FOUNDATION

HTML + CSS

Kinetic CSS is designed around standard HTML and modern CSS. Use its classes, custom properties, fluid sizing, container queries, and design tokens directly in your markup. The core framework does not require JavaScript, a compiler, or a build step.

Compatibility
Native foundation
Requirements
Semantic HTML and modern CSS
Runtime
None required
Build step

FRAMEWORK COMPATIBILITY

React

Kinetic CSS can be used in React applications by importing the stylesheet and applying its classes to JSX elements. The repository lists React as a development dependency, but does not declare a dedicated official React adapter package.

Usage
Apply Kinetic classes in JSX
Styling
Shared CSS stylesheet and design tokens
Official adapter
Not declared in the repository

FRAMEWORK COMPATIBILITY

Vue

Kinetic CSS can be used in Vue applications by importing the stylesheet and applying its classes in component templates. Vue is listed as a development dependency in the repository, not as a separate official Kinetic integration package.
