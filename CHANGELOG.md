# Changelog

## 0.2.0 — 2026-10-30
- Added application patterns: `.k-dialog` (native `<dialog>`), `.k-tabs` (CSS-only tab panels via hidden radios), `.k-accordion` (`<details>`), `.k-menu` (CSS disclosure), `[data-k-tooltip]`.
- Added navigation patterns: `.k-header`, `.k-footer`, `.k-breadcrumb`.
- Added responsive data display: `.k-table`, `.k-table-wrap`.
- Added feedback and loading: `.k-alert` (+ info/success/warning/danger variants), `.k-skeleton`, `.k-progress`, `.k-spinner`, `.k-avatar`.
- Added native control affordance (`accent-color`) for checkboxes and radios.
- Added keyframes: `k-skeleton-slide`, `k-spin`.
- Distribution hardening: npm package metadata, CDN-ready asset layout.

## 0.1.0 — 2026-10-30
- Initial standalone release.
- Fluid type and spacing tokens.
- Container-aware card and navigation primitives.
- Density modes: compact, comfortable, spacious.
- Responsive layout primitives, accessible controls, theme tokens, and reduced-motion handling.
