# 📦 Changelog

## 🚀 0.3.0 — 2026-10-30
- 🌟 **Utility-Component Mashup Evolution**: Transformed Kinetic CSS into a hybrid design toolkit combining Tailwind-style utility atomics with Bootstrap-grade components and Cybercore-Minimalist aesthetics.
- 📐 **12-Column Fluid Grid**: Added `.k-row` and `.k-col-1` through `.k-col-12` grid system with fluid gaps.
- ⚡ **Exhaustive Utility Explosion**: Added comprehensive atomic utility classes covering display, flexbox, grid alignment, fluid padding/margin, typography scales, sizing, borders, shadows, and opacity.
- 💎 **High-Fidelity Components**: Added glassmorphism/glow card variants (`.k-card--glass`, `.k-card--glow`), pure CSS floating labels (`.k-floating`), slide-over offcanvas panels (`.k-offcanvas`), and button groups (`.k-button-group`).
- 🎨 **Enhanced Design Tokens**: Expanded OKLCH color palettes, translucency/blur tokens, and multi-layered elevation shadows.

## 🚀 0.2.0 — 2026-10-30
- ✨ **Application Patterns**: Added `.k-dialog` (native `<dialog>`), `.k-tabs` (CSS-only tab panels via hidden radios), `.k-accordion` (`<details>`), `.k-menu` (CSS disclosure), `[data-k-tooltip]`.
- 🧭 **Navigation Patterns**: Added `.k-header`, `.k-footer`, `.k-breadcrumb`.
- 📊 **Responsive Data Display**: Added `.k-table`, `.k-table-wrap`.
- 🔔 **Feedback & Loading**: Added `.k-alert` (+ info/success/warning/danger variants), `.k-skeleton`, `.k-progress`, `.k-spinner`, `.k-avatar`.
- 🔘 **Native Controls**: Added `accent-color` affordance for checkboxes and radios.
- 🎬 **Animations**: Added `k-skeleton-slide` and `k-spin` keyframes.
- 📦 **Distribution Hardening**: Added npm package metadata, CDN-ready asset layout, and automated multi-package publishing pipeline.

## 🌱 0.1.0 — 2026-10-30
- 🎉 Initial standalone release.
- 📐 Fluid type and spacing tokens via `clamp()`.
- 🧱 Container-aware card and navigation primitives.
- ⚖️ Global density modes: compact, comfortable, spacious.
- ♿ Responsive layout primitives, accessible controls, theme tokens, and reduced-motion handling.
